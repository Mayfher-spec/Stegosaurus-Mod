# Prodigy Chibi Alpha 0.1.0-alpha.1
Forge 1.20.1 / GeckoLib Forge 4.4.9. Standalone mod id **prodigychibi**.
Spawn egg in Creative /sumon prodigychibi:stegosaurus_chibi. Right click with saddle to equip, right click to ride. Shift+right click empty-hand removes saddle.
**Alpha**: test geometry/UV/riding before merging to Prodigy Creatures main mod; no combat or breeding.
